# PC3_CSS_FASANANDO_CARDENAS


### Transformaciones 2D
- **`rotate(4deg)`**: gira una tarjeta 4 grados en 2D
- **`scale(1.06)`**: aumenta el tamaño de la tarjeta al pasar el cursor
- **`translateY(-12px)`**: desplaza la tarjeta hacia arriba

### Transformaciones 3D
- **`perspective(1000px)`**:  profundidad al efecto 3D
- **`transform-style: preserve-3d`**: conserva la disposición tridimensional de los elementos hijos
- **`rotateX()` y `rotateY()`**: giran la tarjeta en los ejes X e Y

### Animaciones CSS
- **`@keyframes`**: define los pasos de una animación.
- **`animation: girar 1s linear infinite`**: hace que el loader gire continuamente.
